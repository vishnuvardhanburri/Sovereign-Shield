# Buyer FAQ

## What is Sovereign Shield?

Sovereign Shield is a human-governed enterprise security platform for private AI governance. It helps organizations keep humans in control while using AI to accelerate analysis, detection, prioritization, and governance.

## What problem does it solve?

It reduces the time required to build an internal security governance layer for AI-bound workflows: PII protection, prompt-injection defense, local routing, audit evidence, risk scoring, dashboards, and due-diligence artifacts.

## Is it a replacement for a CISO team?

No. It is a command center and control platform for security teams. Humans retain accountability for critical actions and risk acceptance.

## Does it require cloud AI providers?

No. The default posture is local-first with Ollama. Cloud adapters are optional and should be enabled only under buyer-approved policy.

## What makes it enterprise-ready?

The repository includes authentication, RBAC, scoped API keys, session revocation, strict CORS, secure headers, audit ledger, evidence generation, deployment scripts, Docker artifacts, and buyer-facing documentation.

## Does it claim legal compliance?

No. It provides technical controls and evidence that support compliance programs. Legal compliance still requires buyer policy, legal review, processor agreements, retention workflows, and control-owner sign-off.

## What is the main acquisition value?

The value is the packaged governance-first security architecture: backend gateway, enterprise command center, local AI governance, audit ledger, evidence reports, deployment materials, and buyer documentation.

## What should buyers test first?

1. Redaction and pseudonymization
2. Prompt-injection blocking
3. Local model routing
4. Risk scoring and quarantine review
5. Audit ledger integrity
6. Evidence report generation
7. Deployment doctor
8. Backup and restore procedure

## What remains buyer-owned?

Infrastructure, secrets, TLS, identity provider policy, backups, retention, legal compliance, SIEM integration, monitoring, alerting, and final approval workflows remain buyer-owned.
